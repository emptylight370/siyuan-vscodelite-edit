## Project Conventions

- **Code structure / key directories**:
  - `theme.scss` 主样式入口；`src/scss/{app,block,plugin}/`，无 `_` 前缀的文件编译为 `sub/` 可选模块
  - `src/ts/` 经 esbuild 打包为 `theme.js`（IIFE）；运行宿主为思源内嵌 WebView（最低 95 / ES2021）
  - `src/ts/settingsSchema.ts` 是配置开关的唯一数据源
- **Mandatory checklists for changes**: 新增配置开关必须走 schema 五步清单（schema 项 → `types.d.ts` → `defs.ts` 文案 → `theme.ts` addImports case → 新建无下划线 SCSS）；编译期 `Assert` 强制 schema 与 ThemeConfig 键一致
- **Lint command**: `pnpm run lint`（stylelint + tsc --noEmit）；格式化由 lefthook pre-commit 调用 prettier
- **Test command**: 无测试框架，需在思源中人工验证

## Change Red Lines

- `theme.json.version` 必须与 `defs.ts` 的 `lastSeen` 字符串同步修改
- 配置结构版本 `vscDefaultConf.version`（整数）不可随意变更
- `changelog.md` 为手工维护文件，不可被工具覆盖
- 可选样式模块的 SCSS 文件名不能带 `_` 前缀（否则 `sub/` 缺文件、运行时 404）
- SCSS 必须守住 WebView 95 语法边界（如禁用 `>= 768px` 范围语法）
- `window.siyuan.isPublish` 为真时禁止写文件、不注入 VC 按钮
